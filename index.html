🩺 USG – Evidența investigațiilor ecografice

USG este o aplicație desktop open-source pentru gestionarea investigațiilor ecografice și a datelor pacienților. Accent pe stocare locală, structurarea informațiilor medicale și rapoarte/formulare tipărite.

⬇️ Descarcă (Releases) 📦 Cod sursă 🇬🇧 README (EN) 🇷🇴 README (RO)

🎯 Scop

  • Crearea unei baze de date independente de pacienți (ecografie)
  • Stocarea datelor investigațiilor ecografice
  • Atașare imagini (formațiuni, calculi etc.)
  • Istoric al pacientului pentru investigații repetate
  • Generare buletine / formulare tipărite personalizate
  • Rapoarte statistice și financiare (în funcție de utilizare)
