# USG Demo

Acesta este un pachet demonstrativ. Datele incluse nu trebuie folosite pentru
activitate medicală reală.

Autorizare:

- utilizator: `admin`
- parolă: nu se introduce (câmp gol)

Instalatorul creează profilul `~/.config/USG/usg_demo.conf`, care indică baza
principală și baza de imagini din subdirectorul `demo` al instalării.
