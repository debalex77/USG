# 🩺 USG – Records of Ultrasound Examinations

**USG** is an open-source desktop application for managing **ultrasound examinations and patient records**.  
The project focuses on **local data storage**, **structured medical information**, and **customizable medical reports**.

It is intended for **individual physicians**, **small clinics**, or **medical offices** that require a **lightweight, offline solution** without cloud or SaaS dependencies.

## 🎯 Purpose

USG was designed to solve common problems encountered in daily ultrasound practice:

- Creation of an **independent local patient database**
- Storage of **ultrasound examination data**
- **Image attachment** (e.g. masses, calculi, pathological findings)
- Building a **longitudinal history** of examined patients
- Generation of **custom printable examination reports**
- Generation of **statistical and financial reports**  
  (useful in commercial or contractual medical activity)

---

## 📖 About the Project

USG provides tools for:

- patient management
- recording ultrasound examinations
- organizing medical data locally
- generating printable medical reports and forms

The application is designed with **extensibility in mind** and can be adapted to different workflows in ultrasound diagnostics.

---

## 🚀 Key Features

- **Patient management** (create, edit, search)
- **Ultrasound examination records**
- **Local database storage**
- **Attachment of ultrasound images**
- **Medical and administrative reports**
- **Printable medical forms**
- **Custom report templates** using LimeReport

---

## 🛠 Technologies Used

- **C++**
- **Qt Framework**
- Desktop application (**cross-platform architecture**)
- **LimeReport** – reporting engine for:
  - medical reports
  - printable forms
  - PDF output
  - custom report layouts
